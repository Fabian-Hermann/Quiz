# Quiz

Ein einfaches Quiz-Projekt zur Anwendung und Vertiefung von Programmierkenntnissen.

# Ziel

Das Projekt dient als Lernprojekt, um grundlegende Programmierkonzepte praktisch umzusetzen und dabei den Umgang mit PowerShell zu lernen.

# Implementierte Funktionen

* Fragen und Antworten extern verwalten
* Funktionen extern verwalten
* Fragentypen verwalten
  * Multiple-Choice-Fragen
  * Offene Fragen
* Benutzereingaben überprüfen
* Levenshtein Distanz
*  Score
* Anpassung der Maximalen Abweichung der Levenshtein Distanz in Relation der länge der richtigen Antwort

# Geplante Funktionen
* 50/50 Joker
* Ladebalken in Diskofarben

# Technologie

* PowerShell
